Approved templates. The agent starts from these for every recurring note type - never freestyle a profile when a template exists.

| Template | Use for |
|----------|---------|
| `wiki-note.md` | Any new `Wiki/` note (workflow, concept, reference, integration, builder) |
| `person-profile.md` | A person in `Wiki/People/` |
| `client-profile.md` | A client or customer in `Wiki/Clients/` |
| `vendor-profile.md` | A supplier or collaborator in `Wiki/Vendors/` |
| `daily-log.md` | A new day file in `Memory/Daily_Logs/` |

Rules:

- Every template's front matter block must be completed per `Schema/schema.md`.
- Every template produces a draft; nothing client- or vendor-facing goes out without an owner's approval.
- A change to a template applies to every future note - propose it to the owners, do not fork silently.
